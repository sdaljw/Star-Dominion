# 小市值：同期板块联动或热门前20

2026-10-07开始实施，2026-10-08完成验证。采用用户最新口径：**有效V4放量确认 AND（同期板块联动 OR 同期热门题材前20）**。两条证据分支独立，命中其中一条即可进入候选。

## 板块联动依据

以下三项须在放量确认当天同时成立：

| 指标 | 当前门槛 |
| --- | --- |
| 板块整体涨幅 | 大于0% |
| 上涨广度 | 上涨家数 /（上涨家数 + 下跌家数）至少60%，不计平盘 |
| 其他同行涨停 | 至少2只，排除候选自身并去重；同行须非ST主板、总市值低于100亿元 |

同行涨停采用日线9.8%至10.2%的涨停形态近似。板块整体涨幅与广度取概念源数据，其覆盖范围可包含其他板股票；买入候选和涨停同行仍限制为合格主板股票。

**连板梯队是增强标记**：其他同行出现至少两个不同连板高度，例如1板与2板。**周期内是增强标记**：同一概念在最近5个实际交易日中至少3日满足上述联动条件。两项均不是当前硬性入场门槛。

## 热门题材依据

股票在确认当日属于同花顺概念涨幅原始排名1至20的题材即可通过热门分支。当前采集地址以 `tradezdf` 降序；这是价格强度代理，未接入新闻或社交人气排行。[同花顺概念数据](https://data.10jqka.com.cn/funds/gnzjl/)

热门分支不额外要求两个同行涨停、60%广度或正涨幅；弱市中相对排名靠前的板块也可能下跌。采集时间须明确、同日盘后且不晚于快照生成时间，原始名次和当时成员须可追溯。第20名通过，第21名仅能依靠联动分支。

“同期”以首次合格放量确认日为准，不能把今天热点倒贴过去；目前也没有在后续第1至3日低吸时重新要求板块仍然活跃。主线面板最多展示5条，入场资格使用完整成功采集的证据，不受展示数量限制。

## 页面与执行

页面分别显示“仅同期板块联动”“仅同期热门题材前20”“板块联动与热门题材均命中”。详情显示板块涨幅、上涨广度、其他同行涨停数量、题材名次和证据日期。来源过期、失败或旧版资格缓存不能进入入场页签。

资格版本升级为3。基础主板、小市值、量价过滤以及1至3个交易日低吸、7%净亏损止损、封板持有至断板、未封板净盈利退出和30日退出沿用现有规则。策略不会执行真实下单。
